# Таксономия классификации

## Домены

- `ai` — ИИ, LLM, промпты, агенты, alignment, guardrails, модели, reasoning
- `career` — поиск работы, резюме, вакансии, интервью, собесы, карьерный рост
- `dev` — разработка, код, баги, библиотеки, инструменты, архитектура
- `infra` — серверы, деплой, VPN, сети, Docker, VPS, мониторинг
- `product` — продукт, метрики, экономика, JTBD, позиционирование, пользователи
- `pm` — управление, процессы, спринты, ретро, планирование, встречи
- `personal` — личное, быт, здоровье, психология, семья, досуг, игры
- `naumen` — Naumen, АОН, AI-офис, корпоративное, обучение сотрудников
- `learning` — обучение, книги, курсы, статьи, исследования, чтение
- `content` — контент, посты, Telegram-канал, LinkedIn, публикации, аудитория

## Проекты и темы

- `stream-bot` → `dev` — бот захвата мыслей: stream.md, триаг, GTD, inbox
- `conspect` → `product` — расширение конспектов: скринкасты, ассистент, кнопки, UI
- `nova-vpn` → `infra` — VPN-сервис: xray-reality, подписки, Hiddify, серверы
- `book-search-bot` → `dev` — поиск книг: flibusta, OPDS, каталог
- `music-search-bot` → `dev` — поиск музыки: трек, плейлист, скачать песню, звук, ffprobe, yt-dlp
- `video-digest` → `dev` — видео в конспект: YouTube, транскрипция, дайджест
- `naumen-aon` → `naumen` — AI-офис: симуляции, тех-собесы, PrjPortal, спринты
- `tg-channel` → `content` — посты, канал, публикации, LinkedIn-дубль
- `job-search` → `career` — отклики, вакансии, интервью, резюме
- `ai-articles` → `ai` — статьи и темы про ИИ: guardrails, alignment, reasoning, persona-векторы
- `learning-materials` → `learning` — курсы, книги, статьи, ссылки для изучения
- `music` → `personal` — музыка для себя: скачать, послушать, подобрать трек
- `home` → `personal` — быт, покупки, документы, финансы
- `gaming` → `personal` — игры, персонажи, прохождения
